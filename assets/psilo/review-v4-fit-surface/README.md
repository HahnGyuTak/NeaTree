# Psilo v4 — 모자 착용과 표면 재검수

사용자가 지적한 모자 위 갓 돌출과 색·재질 차이를 수정한 **승인 전 Blender 검수본**이다. 앱에 번들링하는 USDZ는 교체하지 않았다.

## 수정 내용

- 갓의 원래 볼록한 형태를 유지하며 모자의 뒤·왼쪽 챙, 크라운, 띠가 머리를 덮도록 맞췄다. 앞쪽 챙 끝과 모자 컨트롤의 착용 각도는 보존한다.
- 24fps, 1–289프레임에서 모자 상부 표면 위로 노출되는 갓 정점은 0개다. 검사한 표면의 최소 여유는 1.5304mm다. 이는 외부 관통 검증이며, 모자 내부의 숨은 메시 겹침까지 없는 수밀 모델이라는 뜻은 아니다.
- 산호색, 따뜻한 아이보리와 올리브색을 원화와 비교해 조정했다. 몸통의 짙은 그림자는 별도 스튜디오 보조광으로 보정했다.
- 원화의 균일한 표면 영역에서 색과 큰 명암을 제거한 작은 흑백 종이 질감 타일을 사용한다. 실제 3D 표면에 부착되는 BOX 매핑이며, 캐릭터 이미지를 평면으로 붙이는 방식이 아니다.
- 갓 점무늬를 모델 좌표에서 정의해 위치·기울기를 맞추고 UV 경계의 계단 현상을 줄였다. 입 안쪽의 지나치게 밝은 색도 낮췄다.

## 파일과 확인 범위

- `Psilo-v4.blend`: 중립 제작 원본, 패킹된 재질과 텍스처.
- `Psilo-v4-motion.blend`: 동일 모델의 12초 검수 동작.
- `angle-*.png`: Cycles 정면·좌우 35도.
- `pose-*.png`: 작업, 뿌듯함, 오류, 최저 여유 프레임 210.
- `reference-comparison.jpg`: 같은 너비로 맞춘 원화와 Blender 렌더. 원화와 렌더를 색 보정하지 않고 배치했다.
- `angles-and-actions.jpg`: 여러 각도와 동작 중 자세.
- `motion-review.mp4`: 640×576, 24fps, 289프레임, 12.04초의 오프라인 검수 영상. 앱 실행 화면은 아니다.
- `conform-full-metrics.json`: 289프레임의 외부 노출 검사.
- `conform-integration-report.json`: 이전 변형의 복원·재실행 안정성 검사.
- `build-manifest.json`, `review-manifest.json`: 재생성 및 검수 상태.

스튜디오 조명에서의 비교이며 원화와 완전히 일치했다거나 앱의 최종 외형·성능을 검증했다는 뜻은 아니다. 사용자 승인이 필요하다. 앱 적용 전에는 경량 메시, UV 텍스처 베이크, RealityKit 조명 및 연속 전환 동작을 따로 확인해야 한다. 제작용 노드와 스튜디오 조명을 그대로 앱에 넣지 않는다.

영상은 Eevee 64샘플로 만들고, Cycles와의 색 차이를 줄이도록 영상 렌더에서만 `STUDIO_BodyBounce` 강도를 1.0에서 0.4로 조정했다. 이 설정에서 프레임 88의 주요 표면·몸통은 Cycles 대비 약 2 RGB 이내였다. 원본 `.blend`의 조명은 유지한다. 투명 프레임을 아이보리 배경에 합성했으며 MP4 변환으로 평균 2–3 RGB 차이가 생길 수 있다. 색·질감 비교는 PNG를 기준으로 한다. `motion-render-metadata.json`, `motion-calibration.json`, `motion-video-validation.json`에 조건과 검증 결과를 기록했다.

## 재생성

저장소 루트에서 새 빈 출력 디렉터리를 지정한다. 기존 검수본을 덮어쓰지 않는다.

```sh
blender --background assets/psilo/review-v3-hat/Psilo-v3-hat.blend \
  --python scripts/build-psilo-review-v4.py -- --out /tmp/psilo-v4-new-review
```

빌더는 중립 복원 → 모자 맞춤 → 표면 색 → 점무늬 → 종이 질감 → 검수 동작 순서로 적용한다. 같은 보조 함수들을 실행 중인 Blender MCP 장면에도 적용하고 실제 렌더를 확인했다. 이전 v3에서 별도 출력으로 다시 생성하는 검증을 통과했다.

`psilo-hat-clearance-v4.py`는 갓을 낮춰 모자 아래에 넣던 중간 실험이다. 사선에서 어깨가 꺼져 보여 최종 v4에는 사용하지 않는다. 최종 빌더는 `psilo-hat-conform-v4.py`를 사용한다.
