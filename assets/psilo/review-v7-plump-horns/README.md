# Psilo v7 — 통통하고 둥근 뿔 검수본

**뿔 형태는 2026-11-12 사용자가 확정했다.** 앱 아이콘·메뉴바 아이콘에도 같은 뿔을 반영하도록 요청받았다. 캐릭터 전체 외형·모션의 최종 승인과는 구분하며, 이 제작용 모델 전체를 앱용 USDZ로 교체한 것은 아니다. v6의 갓·몸통·얼굴·모자·재질을 유지하면서, 뿔이 너무 작고 뾰족하다는 피드백을 반영했다.

| 제작 치수 | v6 | v7 |
| --- | --- | --- |
| 원형 밑면 반지름 | 14mm | 18mm |
| 가상 꼭지점까지 높이 | 30mm | 35mm |
| 끝 구면의 반지름 | 0.8mm | 2.5mm |
| 표면에서 밑면 중심까지 매립 깊이 | 6mm | 6mm |

밑면 폭은 약 29% 넓어졌다. 길이도 함께 조정해 넓어진 끝의 둥근 부분 때문에 전체 뿔이 다시 작아 보이지 않도록 했다. 축에 수직인 단면은 원형이며, 각 부착 지점의 갓 법선에 맞춘 방향과 밑면 전체 매립 방식을 유지한다. 끝 구면은 원뿔 측면과 접선 방향으로 이어져 경계가 꺾이지 않는다.

최종 저장된 중립 모델에서 양쪽 밑면 표본 각각 11,073개가 모두 갓 내부에 있다. 최소 매립 깊이는 왼쪽 1.811mm, 오른쪽 1.820mm다. 원형 단면과 표면 법선 방향 정렬도 검사를 통과했다. 검사 보고서에는 실제 Blender 원본의 SHA256을 기록했다.

Blender 5.3의 실제 3D 메시를 Cycles로 렌더링한 결과다. 이미지 생성이나 평면 이미지를 모델의 캡처로 대신하지 않았다. 제작용 조명·셰이더를 사용하므로 앱용 베이크와 실제 앱 표시 검수는 사용자 승인 후 별도로 진행한다. 정지 렌더 검수를 전 프레임의 모션 품질 검증으로 확대하지 않는다.

## 재생성

저장소 루트에서 새 빈 출력 디렉터리를 지정한다.

```sh
blender --background assets/psilo/review-v6-fidelity/Psilo-v6.blend \
  --python scripts/build-psilo-plump-horns-v7.py -- --out /tmp/psilo-v7-review
```

`--draft`는 정면·사선만 낮은 샘플 수로 렌더링한다. 앱 아이콘·메뉴바 아이콘·배포 자산은 이 스크립트가 변경하지 않는다.
