# Psilo v6 — 외형 및 원뿔 뿔 검수본

**사용자 승인 전의 Blender 제작용 모델이다. 앱에 번들링한 USDZ는 아직 교체하지 않았다.**

승인된 아이콘의 실로와 비교해 갓의 윤곽·아랫면 두께, 짧은 받침 몸통, 눈의 매립, 입의 함몰, 모자 폭, 반점과 종이 질감을 수정했다. 이번 뿔 수정은 2026-11-12 사용자가 명시한 원형 단면·둥근 꼭지점·밑면 전체 밀착·갓 기울기와의 정렬을 따른다. 전체 캐릭터가 원화와 일치한다는 최종 승인으로 취급하지 않는다.

## 뿔 구조

- 각 뿔의 축에 수직인 단면은 원이다. 축을 따라 반지름이 일정하게 줄어드는 직선 원뿔이며, 끝부분만 반지름 0.8mm의 작은 구면으로 연결한다.
- 양쪽 부착 위치에서 실제 갓 표면의 법선을 각각 구한다. 뿔 전체를 회전하므로 단면을 타원이나 물방울 모양으로 변형하지 않는다.
- 밑면은 국소 접평면과 나란하게 놓고 갓 안으로 6mm 넣는다. 밑면 반지름은 14mm, 가상의 뾰족한 꼭지점까지 높이는 30mm다. 이는 제작 좌표의 수치다.
- 뿔은 `Horns` 아래에서 `Head`와 함께 움직인다. 밑동을 미끄러뜨리는 별도 지연 회전을 사용하지 않는다.
- 갓의 곡면에 가려지는 부분 때문에 시점에 따라 보이는 길이와 실루엣이 달라진다. 실제 메시의 원형 단면 검사와 렌더 외형 검수는 별도로 수행한다.

최종 중립 장면에서 밑면 표본은 양쪽 각각 **11,073개 전부** 갓 내부에 있다. 가장 얕은 지점도 왼쪽 3.517mm, 오른쪽 3.504mm 안쪽이다. 밑면 법선과 실제 갓 법선의 각도 차이는 왼쪽 약 0.014도, 오른쪽 약 0도이며, 축에 수직인 38개 단면이 원형 검사를 통과했다. 정면·좌우 사선과 작업·완료·오류·복귀의 총 7개 렌더에서 뿔 밑동의 들뜸과 갓의 모자 외부 돌출이 보이지 않는 것을 확인했다. 이는 전 프레임의 시각 검사나 원화 일치 승인을 의미하지 않는다.

289프레임 전체에서 뿔과 갓의 상대 변환 행렬은 허용 오차 내에서 유지된다. 이는 중립 자세의 조밀한 매립 검사와 결합한 검증이며, 모든 프레임에서 같은 조밀한 검사를 반복했다는 뜻은 아니다. 안경을 쓴 88·106·207·210프레임의 앞쪽 테두리·브리지는 갓 표면에서 최소 2.174mm 떨어져 있다.

## 재생성

저장소 루트에서 새 빈 출력 디렉터리를 지정한다. Blender `bpy`로 실제 메시와 장면을 수정하고 Cycles로 렌더링한다. 이미지 생성 결과나 평면 캐릭터를 Blender 캡처로 대신하지 않는다.

```sh
blender --background assets/psilo/review-v5-short-horns/Psilo-v5.blend \
  --python scripts/build-psilo-review-v6.py -- --out /tmp/psilo-v6-review
```

접촉 검사는 `scripts/check-psilo-contacts-v6.py`를 사용한다. 완전히 매립한 평면 밑면에는 곡면과의 영거리 접촉 조건을 적용하지 않는다. 대신 밑면 정점·둘레·삼각면 내부가 전부 갓 내부인지, 단면이 원형인지, 뿔의 축이 표면 법선과 일치하는지 확인한다.

## 남은 검수

이 장면은 제작용 조명과 셰이더를 사용한다. 사용자 외형 승인 후 앱용 재질 베이크·메시 경량화·표정 연결을 진행하고, 실제 앱의 표시 크기와 조명에서 다시 검수해야 한다. 이 폴더의 정지 프레임만으로 모든 동작 전환의 자연스러움이나 앱 성능 검증이 완료됐다고 판단하지 않는다.
