# NeaTree 캐릭터 배치와 행동

2026-11-11 사용자 요구사항 기록. 배치는 승인됐으며 아래 모션은 제작 요구사항이다. 이 문서가 실제 움직임 구현·검수 완료를 뜻하지 않는다.

## 승인된 배치

- 파일이 없는 화면은 [시안 3](mascot-empty-v1.png)처럼 목록 중앙에 큰 캐릭터와 안내 문구를 배치한다.
- 파일이 있는 화면은 [시안 1](mascot-sidebar-v1.png)처럼 사이드바 하단에 작은 캐릭터를 배치한다.
- 한 창에 같은 캐릭터를 중복 표시하지 않는다. 검색 결과가 없다는 이유만으로 앱 전체가 비었다고 판단하지 않는다.
- 위치가 바뀔 때 같은 행동 상태를 이어가고, 새 캐릭터가 등장한 것처럼 행동을 초기화하지 않는다.

## 사용자가 요청한 행동

| 상태 | 행동과 전환 |
| --- | --- |
| 평상시 | 멍한 기본 표정, 느린 호흡과 간헐적인 눈 깜빡임. 앱 창의 커서를 눈이 먼저 보고 고개가 조금 늦게 따라간다. |
| 파일 분류·폴더 구조 분석 시작 | 하던 시선 동작에서 작업으로 주의를 돌림 → 주변에 파일·폴더가 날아와 쌓임 → 안경이 얼굴에 안착 → 몸을 조금 숙이고 파일을 살펴봄. |
| 작업 중 | 안경을 유지하고 파일을 번갈아 바라보거나 고개를 끄덕이며 작은 종이 동작을 이어감. 소품은 캐릭터 영역 안에서만 움직임. |
| 완료 | 작업을 마무리하고 뿌듯한 표정을 지음 → 팔 없는 몸과 갓을 두세 번 들썩이며 으쓱함 → 소품과 안경을 정리하며 평상시로 돌아감. |
| 오류 | 현재 자세에서 눈이 빙글 돌고 비틀거림 → 오류가 남아 있는 동안 작은 흔들림 유지 → 해결 후 균형을 잡고 기본 표정으로 복귀. |

표정·안경·소품을 즉시 다른 그림으로 교체하지 않는다. 현재 위치, 기울기, 움직이는 속도에서 다음 목표 자세로 연결한다. 모자·뿔·갓은 몸보다 약간 늦게 반응해 부드러운 무게감을 낸다. 커서 추적은 작업 중에는 파일을 보는 행동에 양보한다.

작업이 매우 짧으면 진입 동작을 압축하고 결과로 이어간다. 연속 작업에서는 안경 착탈과 파일 도착 연출을 매 항목마다 반복하지 않는다. 완료 동작 도중 새 작업이 오면 짧게 이어 받아 다시 작업하며, 오류는 축하 동작보다 우선한다. 취소는 성공 동작 없이 대기로 복귀한다.

## 권장 제작 방식

현재처럼 주로 정면을 보며 작은 고개 움직임을 하는 캐릭터에는 **부위별 2D 원화와 입체감 있는 변형을 조합하는 2.5D 리깅**을 우선 권장한다. SpriteKit의 노드 계층·이미지 변형과 SwiftUI 호스팅을 후보로 삼는다. 이는 아직 성능 검증된 구현 선택을 뜻하지 않는다. 옆·뒷모습을 크게 보이거나 실제 시점·조명 변화가 필요하면 3D 모델과 표정·골격 리깅을 제작하고 RealityKit 렌더링을 검토한다.

현재 아이콘은 배경·파일·캐릭터가 분리됐지만, 캐릭터 자체의 눈과 입은 한 이미지에 포함되어 있다. 시선과 표정을 독립적으로 움직이려면 갓·몸, 눈·입, 모자·뿔, 안경, 개별 파일·폴더와 그림자 등 애니메이션용 원화를 별도로 준비한다. 작업·기쁨·오류의 얼굴 변화도 자연스럽게 연결할 수 있게 만든다. 기존 PNG 전체를 흔드는 것만으로 동작을 완성한 것으로 보지 않는다.

## 앱 상태와 연결

- `isBusy` 하나로 행동을 선택하지 않는다. 다운로드 감시·설정 저장과 파일 분석·구조 분석·실제 이동을 구분한다. 감시 폴링마다 작업 진입 동작을 반복하지 않는다.
- 작업 ID, 종류, 시작·진행·완료·실패·취소와 결과를 명시적인 이벤트로 전달한다. `statusMessage`의 문구를 해석하지 않는다.
- 제안 준비, 규칙 후보 준비, 실제 파일 이동 완료를 다른 결과로 구분한다. 제안만 준비됐을 때 파일 정리가 완료됐다고 표현하지 않는다.
- 묶음의 부분 실패도 오류 결과로 전달한다. 오래된 작업의 완료가 새 작업이나 오류 동작을 덮지 않도록 작업 ID를 확인한다.
- 오류 알림을 닫는 것과 실제 문제가 해결된 것을 구분한다. 복구 시도·성공 또는 해당 문제가 더 이상 유효하지 않다는 서비스 판단으로 오류 상태를 해제한다.
- 앱 창이 보일 때만 시선 추적과 연속 렌더링을 수행한다. 숨김·최소화 상태에서는 쉬고, 다시 보일 때 현재 작업 상태로 부드럽게 복귀한다.
- 동작 줄이기를 켜면 비행·비틀거림·회전을 최소화하고 표정과 상태 문구로 전달한다. 캐릭터와 소품이 클릭·드래그·키보드 입력을 가리지 않게 한다.

## 다음 검증

시선 추적 → 파일 도착과 안경 착용 → 작업 → 완료/오류 → 복귀를 한 장면에서 확인할 수 있는 실제 모션 프로토타입으로 연결감을 검증한다. 상태를 도중에 바꾸는 경우와 큰 중앙 배치·작은 사이드바 배치에서도 동작이 이어지는지 확인한다.
