# 승인된 짧은 뿔 적용

2026-11-11 사용자의 “오케이”는 [짧은 뿔 시안](../../assets/psilo/reference/short-horns-approved-v1.png)에 대한 확정이다. 꺾임 없는 넓은 밑동, 짧은 길이, 끝만 살짝 뾰족하고 둥글게 마무리한 형태를 적용했다.

## 적용 범위

- 앱 아이콘: 승인 원화를 캐릭터 레이어에 반영했다. 유리 배경과 파일·폴더 더미 레이어를 유지하며 Default, DarkAqua, Tintable 모두 3개 레이어로 컴파일된다. [일반](icons-short-horns-default.png) · [어두운 외형](icons-short-horns-dark.png)
- 메뉴바: 문서 위 버섯 갓 구성에 짧은 뿔을 반영했다. 모자·얼굴 없이 단색 템플릿과 투명도를 유지했다. [밝고 어두운 배경 검토](menu-short-horns-light-dark.png)
- Blender: 정밀 제작용 v5, 기존 앱용 모델, 별도 MCP 원본에 같은 형태를 적용했다. 기존 동작 컨트롤과 나머지 부위는 유지했다. [v5 원본·다각도·동작 렌더](../../assets/psilo/review-v5-short-horns/README.md)

## 검증

- `actool` 아이콘 레이어 컴파일, 18×18·36×36 메뉴바 템플릿 규격·투명도 확인.
- Blender 뿔 메시의 닫힘·양의 부피·퇴화 면 없음, 텍스처 패킹과 상대 경로 확인.
- `usdchecker --arkit` 통과. 앱 USDZ의 뿔 외 83개 prim 및 43개 중립 변환이 기존과 동일하다. [검증 결과](../../assets/psilo/blender/usdz-rig-check.json)
- 앱 모델은 25,756개 삼각형, 27개 메시, 6개 재질, 768×768 텍스처 한 장, 671,098바이트다.
- Debug 개발 빌드 0.1.0-b8 빌드·패키징·ad-hoc 서명 검증을 통과했다. USDZ와 메뉴바 이미지의 소스·앱 번들 해시가 일치한다. [패키지 검증](../../assets/psilo/short-horns-app-verification.json)
- 실제 macOS 동작 확인 창에서 대기, 파일 분석의 안경·파일 소품, 오류의 나선 눈, 복구, 폴더 분석과 완료 전환을 확인했다. 별도 데모 상태만 사용했으며 실제 다운로드나 API를 사용하지 않았다.

첫 패키징은 Documents 하위에 자동으로 붙은 Finder 메타데이터로 서명 검증이 실패했다. 임시 폴더에서 재패키징한 결과는 정상 검증됐다. 이 산출물은 로컬 개발 빌드이며 공증 또는 GitHub 배포를 수행하지 않았다.

뿔 승인과 정밀 모델 전체의 승인을 구분한다. 이번 앱용 USDZ 교체는 뿔만 변경했으며, v5 정밀 몸체·종이 재질 전체의 앱 적용과 최종 외형·모션 검수는 별도로 남아 있다. 상태 화면 확인을 모든 애니메이션 프레임·성능·전력 검증으로 해석하지 않는다.
