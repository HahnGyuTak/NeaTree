# NeaTree 개발 검증 기록

2026-11-11, macOS 27.2 SDK / Swift 6.4.2 / Apple Silicon 환경에서 확인했다.

- `swift test`: 57개 통과 (XCTest 19개, 코어 Swift Testing 28개, 앱 모델 10개).
- 본창·설정·메뉴바를 포함한 `file-organizer` 실행파일 컴파일 성공.
- `scripts/pack-app.sh`: NeaTree.app와 ZIP 생성, ad-hoc 코드 서명 검증 성공.
- 배포 shell, workflow YAML, Info.plist 문법 검사 통과.
- 파일 처리 검증은 임시 파일을 사용했고 실제 사용자 다운로드·문서에는 실행하지 않았다.
- 앱 모델 검증은 분석 동의, API 오류 시 자동 분석 일시중지, 취소, 변경된 파일의 옛 초안 적용 거절, 이동·되돌리기·미분류·재검토, 시작 시 이동 기록 복구, 데모의 키 접근 차단을 포함한다.

현재 앱의 화면·실제 메뉴바·키보드 초점·모션은 데모 실행 승인을 받은 뒤 확인할 예정이다. 자동 승인 검토가 출처 미확인 로컬 앱의 실행 직전 사용자 확인을 요구하여 첫 실행은 차단되었다. 기존 독립 디자인 미리보기 확인과 이번 전체 앱 검증은 구분한다.

실제 API 호출과 모델의 분류 품질, Developer ID 서명·공증, 다른 OS/Intel Mac에서의 실행은 아직 검증하지 않았다. 기본 개발용 앱을 정식 배포 빌드로 취급하지 않는다.
