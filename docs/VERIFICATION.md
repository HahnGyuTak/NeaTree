# NeaTree 개발 검증 기록

2026-11-11, macOS 27.2 SDK / Swift 6.4.2 / Apple Silicon 환경에서 확인했다.

- `swift test`: 88개 통과 (XCTest 19개, 코어 Swift Testing 47개, 앱 모델 22개).
- 본창·설정·메뉴바를 포함한 `file-organizer` 실행파일 컴파일 성공.
- `scripts/pack-app.sh`: NeaTree.app와 ZIP 생성, ad-hoc 코드 서명 검증 성공.
- 배포 shell, workflow YAML, Info.plist 문법 검사 통과.
- 파일 처리 검증은 임시 파일을 사용했고 실제 사용자 다운로드·문서에는 실행하지 않았다.
- 앱 모델 검증은 분석 동의, API 오류 시 자동 분석 일시중지, 취소, 변경된 파일의 옛 초안 적용 거절, 이동·되돌리기·미분류·재검토, 시작 시 이동 기록 복구, 데모의 키 접근·외부 파일 및 심볼릭 링크 우회 차단을 포함한다.
- 추가 검증: 규칙 생성·편집·삭제와 버전 무효화, 제외 설정 저장·수동 가져오기 예외, 동일 경로의 새 파일과 대소문자 구분, 편집 초안 재시작 복원·빈 입력, 순차 일괄 적용·부분 실패·번호 충돌·일괄 되돌리기.
- 실제 감시 Task가 새 임시 파일의 안정화를 확인하고 모형 분석을 거쳐 제안을 한 번 알리는 흐름을 통합 테스트했다. 보류한 파일을 반복 제안하지 않는 것도 확인했다.
- 이미지와 텍스트 레이어 없는 PDF를 생성해 Apple Vision으로 실제 글자를 읽는 검증을 통과했다. 크기·페이지·문자 한도, 부분 인식, 실패 상태와 진단 정보의 개인정보 제외도 테스트했다.

개발 셸의 샌드박스에서는 Vision이 `VNErrorDomain:8`을 반환했다. 시스템 인식 서비스에 접근할 수 있는 실행 환경에서 전체 88개가 통과했다. 최초 Vision 준비가 60초 제한을 넘긴 사례가 있어 OCR 테스트 제한은 2분이며, 검증을 생략하지 않는다.

사용자가 데모 실행을 허용한 뒤 네이티브 화면에서 다음을 확인했다.

- Finder 형태 본창, 설정, 내용 미리보기, 한글 파일명 편집과 적용
- 정리 이력과 되돌림, 보류, 미분류 이동과 미리보기
- 메뉴바 제안창의 실제 재질·텍스트, 적용과 본창 이력 연동, 취소 후 다음 항목 전환, Esc 닫기
- 창 확대와 앱 재실행, 데모에서 실제 API 키 편집 비활성화
- 편집한 이름의 항목 전환 후 유지, 빈 이름 적용 비활성화, `{serial}`을 제거한 고정 이름의 적용과 실제 정리 이력

메뉴바 제안창은 메뉴/키보드로 직접 열어 확인했다. 새 다운로드부터 자동 분석·자동 표시까지의 전체 흐름, 다른 앱에서 입력 중일 때 초점 유지, 실제 드래그앤드롭, 로그인 실행, 다크 모드·접근성 설정 조합은 추가 수동 확인이 필요하다. 자동 감시와 분석 취소 자체는 앱 모델 테스트에 포함한다.

GitHub의 macOS 26 / Xcode 26.6 환경에서도 테스트·앱 빌드·개발용 ZIP 업로드를 통과했다. SwiftPM의 진입점 처리를 위해 `@main` 앱 파일은 `NeaTreeApp.swift`로 분리했다.

실제 API 호출과 모델의 분류 품질, Developer ID 서명·공증, 다른 OS/Intel Mac에서의 실행은 아직 검증하지 않았다. 기본 개발용 앱을 정식 배포 빌드로 취급하지 않는다.
