# NeaTree 개발 검증 기록

## 2026-11-12 관리 화면·API·v7 통합

- 최종 전체 자동 테스트 117개 통과: XCTest 19개, 코어 Swift Testing 63개, 앱 모델 35개. 임시 파일과 모형 API 응답만 사용했다.
- 사용자 허용 범위 내 실제 API 5회가 모두 기대 결과를 반환했다. [사례·사용량·검증 한계](API_VALIDATION.md)를 따로 기록했다.
- UTF-8/RTF 키 파일 가져오기와 명시적 유료 연결 검증을 구현했다. 데모에서 키 읽기·쓰기·검증 호출을 차단하고, 키 변경 시 이전 검증 결과를 무효화하는 테스트가 통과했다.
- 네이티브 개발 앱에서 ⌘ 다중 선택, 한글 이름 편집, 편집 시 확인 해제, 파일별 확인 후 일괄 적용(2/2 성공), 결과 표시, 이력 다중 선택·복구 계획·되돌리기(2/2 성공)를 확인했다.
- 실제 Quick Look에 복구된 원본 텍스트가 표시됐고 Escape로 닫혔다. 규칙 생성·저장과 감시 제외 저장, 저장하지 않은 설정의 Escape 보호도 확인했다.
- 실행 중인 데모의 임시 다운로드 폴더에 TXT와 제외 확장자 ZIP을 함께 추가했다. TXT만 검토함에 들어와 모형 분석·제안 준비를 완료했다. b12의 자동 팝업 검사에서 `panelVisible=true`, `frontmostPIDUnchanged=true`, `panelNotKey=true`를 확인했다. 화면 관찰 도구가 앱을 활성화하기 전에 기록한 결과이며, 별도로 직접 연 제안창의 내용과 버튼도 확인했다.
- 최신 전체 v7 USDZ를 번들링하고 대기·안경/파일 작업·완료 표정·오류 나선 눈·복구를 실제 RealityKit 창에서 확인했다. 최소화·숨김·설정 표시에서 렌더러 해제 로그를 확인했다. b13에서 Display P3 출력 감지와 GPU 색상 보정이 동작했고, `native=0, mesh fallback=4, complete=1` 상태의 실제 웃는 눈·닫힌 입을 확인했다. 이름만 매핑되고 변형 데이터가 없는 native 채널은 사용하지 않는다. 원본과 일부 밝기 차이는 남으며 최종 시각 승인은 사용자 검수 대상이다.


- 설정 저장 직후 성공 안내가 유지되는 것을 확인했다. 폴더 선택란은 구분 가능한 가장 짧은 이름을 표시하며, 전체 경로는 아래에 별도로 보여준다. 같은 이름이 중복되면 필요한 상위 폴더를 덧붙인다.
- b13에서 임시 파일 2개를 실제 적용한 뒤 검토함이 0개가 되면 실로가 중앙으로 이동하는 상태를 확인했다. 이력이 남아 있어도 빈 검토함 배치를 방해하지 않는다.
- 숨김 상태에서 감시가 켜진 개발 빌드의 짧은 CPU 표본은 0.3~0.8%였다. 이는 이 맥의 특정 실행 상태이며 FPS·GPU 비용·배터리 시간·다른 기기 성능을 보증하지 않는다.
- v7 모델은 5,014,102바이트 USDZ, 표시 삼각형 41,219개, 재질 2개, 텍스처 3개다. 숨겨진 표정 대체 메시 24,935개 삼각형은 로딩 후 장면에서 제거한다. GPU 색상 LUT는 287,496바이트이며 한 번 캐시한다.
- Blender 원본 19개와 공개 PNG 메타데이터를 정리했고, 기하·재질·텍스처 픽셀 유지와 최종 아티팩트 해시 참조 402개 일치를 별도 검사했다.


- b14 일반 실행에서 환경변수 없이 기존 Keychain 키의 등록 상태가 설정에 표시되는 것을 확인했다. 시작 시 실제 키를 읽던 호출의 대기를 제거하고, 비대화식 메타데이터 조회를 UI 스레드 밖으로 분리했다. 늦게 끝난 조회가 저장·삭제 결과를 덮어쓰지 않는 회귀검사도 통과했다. 이 GUI 확인에서 API는 호출하지 않았다.
- 공개 전 검사 대상 285개 파일에서 인증정보 후보·개인 경로·100MB 이상 파일이 없었다. 해시 참조 402개는 모두 현재 산출물과 일치했다. 가상의 개인정보 제거 테스트 경로, 일반적인 `/tmp` 사용 예시와 명시적인 과거 빌드 기록은 현재 자료와 구분했다.


## 이전 검증 기록

2026-11-11, macOS 27.2 SDK / Swift 6.4.2 / Apple Silicon 환경에서 확인했다.

- `swift test`: 88개 통과 (XCTest 19개, 코어 Swift Testing 47개, 앱 모델 22개).
- 본창·설정·메뉴바를 포함한 `file-organizer` 실행파일 컴파일 성공.
- `scripts/pack-app.sh`: NeaTree.app와 ZIP 생성, ad-hoc 코드 서명 검증 성공.
- 배포 shell, workflow YAML, Info.plist 문법 검사 통과.
- 파일 처리 검증은 임시 파일을 사용했고 실제 사용자 다운로드·문서에는 실행하지 않았다.
- 앱 모델 검증은 분석 동의, API 오류 시 자동 분석 일시중지, 취소, 변경된 파일의 옛 초안 적용 거절, 이동·되돌리기·미분류·재검토, 시작 시 이동 기록 복구, 데모의 키 접근·외부 파일 및 심볼릭 링크 우회 차단을 포함한다.
- 추가 검증: 규칙 생성·편집·삭제와 버전 무효화, 제외 설정 저장·수동 가져오기 예외, 동일 경로의 새 파일과 대소문자 구분, 편집 초안 재시작 복원·빈 입력, 순차 일괄 적용·부분 실패·번호 충돌·일괄 되돌리기.
- 실제 감시 Task가 새 임시 파일의 안정화를 확인하고 모형 분석을 거쳐 제안을 한 번 알리는 흐름을 통합 테스트했다. 보류한 파일을 반복 제안하지 않는 것도 확인했다.
- 이미지와 텍스트 레이어 없는 PDF를 생성해 Apple Vision으로 실제 글자를 읽는 검증을 통과했다. 크기·페이지·문자 한도, 부분 인식, 실패 상태와 진단 정보의 개인정보 제외도 테스트했다.

개발 셸의 샌드박스에서는 Vision이 `VNErrorDomain:8`을 반환했다. 시스템 인식 서비스에 접근할 수 있는 실행 환경에서 전체 88개가 통과했다. 최초 Vision 준비가 60초 제한을 넘긴 사례가 있어 OCR 테스트 제한은 2분이며, 검증을 생략하지 않는다.

사용자가 데모 실행을 허용한 뒤 네이티브 화면에서 다음을 확인했다.

- Finder 형태 본창, 설정, 내용 미리보기, 한글 파일명 편집과 적용
- 정리 이력과 되돌림, 보류, 미분류 이동과 미리보기
- 메뉴바 제안창의 실제 재질·텍스트, 적용과 본창 이력 연동, 취소 후 다음 항목 전환, Esc 닫기
- 창 확대와 앱 재실행, 데모에서 실제 API 키 편집 비활성화
- 편집한 이름의 항목 전환 후 유지, 빈 이름 적용 비활성화, `{serial}`을 제거한 고정 이름의 적용과 실제 정리 이력

메뉴바 제안창은 메뉴/키보드로 직접 열어 확인했다. 새 다운로드부터 자동 분석·자동 표시까지의 전체 흐름, 다른 앱에서 입력 중일 때 초점 유지, 실제 드래그앤드롭, 로그인 실행, 다크 모드·접근성 설정 조합은 추가 수동 확인이 필요하다. 자동 감시와 분석 취소 자체는 앱 모델 테스트에 포함한다.

GitHub의 macOS 26 / Xcode 26.6 환경에서도 테스트·앱 빌드·개발용 ZIP 업로드를 통과했다. SwiftPM의 진입점 처리를 위해 `@main` 앱 파일은 `NeaTreeApp.swift`로 분리했다.

이전 기록 시점에는 실제 API를 검증하지 않았으며, 이후 결과는 위 2026-11-12 기록에 있다. Developer ID 서명·공증과 다른 OS/Intel Mac의 실제 실행은 여전히 별도 검증이 필요하다. 기본 개발용 앱을 정식 배포 빌드로 취급하지 않는다.
