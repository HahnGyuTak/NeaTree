사용자가 허용한 총 5회 안에서 `gpt-6.1-sol`을 검증했다. 모두 앱의 Responses API 어댑터와 구조화 출력 검증을 사용했다. 개인 문서 대신 합성 폴더·텍스트만 전송했고, 자동 재시도나 추가 호출은 하지 않았다.

| 호출 | 확인한 동작 | 결과 |
| --- | --- | --- |

첫 두 연결 검증 요청은 합계 2,303토큰(입력 1,710, 출력 593)을 사용했다. 후속 세 요청은 CLI의 실제 분류 경로로 실행했으며 토큰 사용량은 별도 수집하지 않았다. 따라서 2,303은 전체 다섯 요청의 합계가 아니다.

후속 세 파일은 동일한 임시 상태 저장소에서 적용 또는 미분류 이동을 실행한 뒤 전부 되돌렸다. 세 원본의 SHA-256이 이동 전 값과 일치했다. 이동·되돌리기는 추가 API 요청 없이 실행했다.

이 검증은 기본 연결과 다섯 합성 사례의 결과다. 모든 문서의 분류 정확도, 모든 프롬프트 주입 방어, 기기·계정별 접근을 보증하지 않는다. 실제 문서의 제안은 사용자가 검토한 뒤 적용한다. API 키·원본 키 문서·계정 응답 원문은 저장소나 앱 번들에 포함하지 않는다.
