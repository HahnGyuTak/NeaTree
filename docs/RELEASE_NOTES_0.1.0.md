# NeaTree 0.1.0 미리보기 — 릴리스 노트 초안

NeaTree는 다운로드한 파일의 이름과 보관 위치를 제안하고, 사용자가 검토한 뒤 적용하는 macOS 파일 정리 도우미입니다.

- 다운로드 감시·드래그 입력, 내용 기반 제안, 이름·위치 편집, 번호 배정
- 규칙 생성·편집·확정과 확장자·하위 폴더 감시 제외
- 다중 선택·파일별 검토·공통 목적지, 일괄 적용·보류·미분류, 항목별 결과
- Quick Look 원본 미리보기, 정리 이력과 선택 항목 되돌리기
- 메뉴바 제안창과 선택형 자동 분석
- 최신 실로(Psilo) 3D 모델, 작업·완료·오류 표정과 연속 움직임
- 텍스트·RTF API 키 파일의 Keychain 가져오기와 명시적 연결 검증

macOS 14 이상을 대상으로 합니다. 이번 로컬 검수 환경은 Apple Silicon·macOS 27이며, Intel과 다른 지원 OS의 실제 실행 검증은 별도입니다. OpenAI API 키와 사용 요금은 사용자 계정에 따릅니다. 자동 분석은 기본적으로 꺼져 있고, 파일 이동은 검토 후 적용할 때만 실행합니다.

현재 이동은 동일 볼륨을 지원합니다. OCR은 일부 내용만 인식할 수 있으며, 제안 정확도를 보장하지 않습니다. 프로젝트 관련성에 따른 자동 묶음, 개정본 비교, 미분류 사유·재검토 추천과 규칙 우선순위 편집은 후속 범위입니다.

**배포 상태:** 이 문서는 초안입니다. 로컬 개발 패키지는 ad-hoc 서명이며 공증된 정식 다운로드가 아닙니다. Developer ID 서명·Apple 공증·최종 설치 확인을 마친 패키지에만 정식 릴리스 표시를 적용합니다. 현재 코드는 개발·검수용이며 GitHub Release가 이미 공개되었다는 뜻이 아닙니다.

검증 범위는 [개발 검증 기록](VERIFICATION.md), 실제 모델 사례는 [API 검증 기록](API_VALIDATION.md)에 있습니다.
