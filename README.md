# NeaTree

**Neat(깔끔한) + Tree(디렉토리 구조)**

다운로드한 파일과 폴더의 내용을 살펴보고, 기존 폴더 구조와 명명 규칙에 맞는 이름·위치를 제안하는 macOS 앱입니다. 사용자가 검토하고 적용할 때 파일을 이동하며, 미분류·보류·이력·되돌리기를 지원합니다.

Finder의 사이드바·목록·검토 영역에 Liquid Glass 컴포넌트를 연결한 첫 개발 버전입니다. 배포 채널은 **[GitHub Releases](https://github.com/HahnGyuTak/mac-file-organizer/releases)**입니다. 아직 서명·공증된 정식 릴리스는 없습니다.

## 사용 흐름

1. 설정에서 다운로드 폴더와 보관할 폴더를 선택합니다.
2. API 키를 macOS 키체인에 저장하고 기존 구조를 분석해 규칙 후보를 확인합니다. 키 없이도 직접 이름과 위치를 지정할 수 있습니다.
3. 다운로드 감시를 켜거나 파일·폴더를 앱에 끌어 넣습니다.
4. 분석을 요청하고 제안 이름·위치·근거를 검토합니다. 이름·목적지·번호 옵션을 수정할 수 있습니다.
5. 적용, 원래 위치에 보류, `다운로드/미분류` 이동 중 선택합니다. 이력에서 되돌릴 수 있습니다.

창을 닫아도 메뉴바 아이콘과 활성화한 감시는 유지됩니다. 자동 분석을 켜면 안정화된 새 파일을 분석한 뒤 아이콘 아래에 제안창을 표시합니다. 자동 표시는 다른 앱의 키보드 초점을 가져오지 않으며, 메뉴바를 직접 누르면 제안창을 다시 열 수 있습니다. 취소는 파일을 이동하지 않고 보류합니다. 오른쪽 클릭 메뉴에서 검토함·설정·감시·로그인 시 실행·종료를 선택합니다.

## 빌드와 실행

macOS 14 이상, Swift 6과 Xcode 26 이상이 필요합니다. macOS 26 이상에서는 네이티브 Liquid Glass를 사용하고, 이전 버전은 재질 기반 대체 표현을 사용합니다.

```sh
swift test
scripts/pack-app.sh --version 0.1.0 --no-dmg
```

`dist/NeaTree-...-development/NeaTree.app`과 ZIP이 생성됩니다. 기본 패키지는 로컬 개발용 ad-hoc 서명이며 공증된 다운로드가 아닙니다. Developer ID 서명·공증·GitHub 릴리스 초안 준비는 [배포 문서](docs/DISTRIBUTION.md)를 따릅니다.

```sh
# 임시 샘플 파일과 모형 제안으로 실행 (실제 다운로드·API 키를 사용하지 않음)
swift run file-organizer --demo

# 개발용 CLI와 독립 디자인 미리보기
swift run organizer help
swift run organizer-design-preview
```

API 분석에는 사용자의 OpenAI API 키가 필요합니다. 폴더 선택·파일 가져오기만으로 API에 자료를 전송하지 않으며, 분석을 요청하거나 자동 분석을 켰을 때 선택한 범위의 파일명·경로·추출 내용이 전송됩니다. 설정의 자동 분석은 기본으로 꺼져 있습니다. API 인증·한도·서버 오류가 발생하면 자동 분석을 일시중지합니다.

## 현재 범위

- 다운로드 안정화 확인, 파일·폴더 드래그 입력, 편집 가능한 제안과 근거, 구조 분석과 규칙 후보 확정
- 실제 적용 시 번호 배정, 동일 내용 탐색, 덮어쓰기·원본 변경·경로 이탈 방지
- 보류 상태 저장, 미분류 이동과 수동 재검토, 이동 이력·되돌리기
- 메뉴바 제안창, 로그인 시 실행 선택, Keychain API 키, 동작·투명도 줄이기 지원

현재 이동은 동일 볼륨의 일반 파일·폴더를 지원합니다. 추출은 텍스트·PDF 텍스트·폴더 목록을 지원하며 자세한 크기 한도는 [코어 문서](docs/CORE_USAGE.md)에 있습니다. 실제 모델의 분류 품질과 계정별 API 접근은 키를 설정한 뒤 확인해야 합니다.

기획안의 확장 기능 중 규칙 직접 편집·삭제, 사용자 지정 감시 제외 UI, 앱 재시작 후 이름·위치 편집 초안 복원, 다중 선택 적용, 프로젝트 묶음 제안, Quick Look·OCR, 개정본 비교, 미분류 사유 메모는 후속 구현 범위입니다. 현재 편집 초안은 실행 중 항목 전환 동안 유지됩니다.
